--------------------------------------------------------------------------------

Write a function:

def mirror_matrix_vertical(matrix: list) -> list:

Returns a new matrix mirrored vertically, meaning the order of rows is
reversed.
Rows themselves remain unchanged.
The original matrix must not be modified.

Example:

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

mirror_matrix_vertical(matrix) →

[
    [7, 8, 9],
    [4, 5, 6],
    [1, 2, 3]
]


You may use this to test your code prior to submission:

res = mirror_matrix_vertical([
                               [1, 2, 3],
                               [4, 5, 6],
                               [7, 8, 9]
                             ])

print("[")
for i, row in enumerate(res):
    comma = "," if i < len(res) - 1 else ""
    print(f"  {row}{comma}")
print("]")
