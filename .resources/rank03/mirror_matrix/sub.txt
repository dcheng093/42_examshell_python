Assignment name  : mirror_matrix
Expected files   : mirror_matrix.py
--------------------------------------------------------------------------------

Write a function:

def mirror_matrix(matrix: list[list[int]]) -> list[list[int]]:

Returns a new matrix where each row is reversed horizontally.
The original matrix must not be modified.

Example:

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

mirror_matrix(matrix) →

[
    [3, 2, 1],
    [6, 5, 4],
    [9, 8, 7]
]


You may use this to test your code prior to submission:

res = mirror_matrix([
                               [1, 2, 3],
                               [4, 5, 6],
                               [7, 8, 9]
                             ])

print("[")
for i, row in enumerate(res):
    comma = "," if i < len(res) - 1 else ""
    print(f"  {row}{comma}")
print("]")
